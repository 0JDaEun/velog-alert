휴대폰 알림

휴대폰 알림 사용

PC가 켜져 있을 때는 모든 활성 알림을 전달하고, PC가 꺼져 있어도 팔로잉 사용자의 공개 새 글은 Cloud에서 약 1분 간격으로 확인합니다.

1

연결 코드 만들기

코드는 10분 동안 한 번만 사용할 수 있습니다.

연결 코드 --- 10분 안에 휴대폰에서 입력하세요.
2

휴대폰에 Velog Alert 추가하기

휴대폰 브라우저에서 아래 주소를 열고 홈 화면에 Velog Alert를 추가합니다.

https://velog-alert-mobile.netlify.app
Android · Chrome
  1. Chrome에서 위 주소를 엽니다.
  2. 브라우저 메뉴(⋮)에서 앱 설치 또는 홈 화면에 추가를 선택합니다.
  3. 홈 화면에 생긴 Velog Alert를 실행합니다.
  4. PC에 표시된 6자리 연결 코드를 입력합니다.
  5. 알림 허용 및 연결을 누르고 알림 권한을 허용합니다.
iPhone · Safari
  1. Safari에서 위 주소를 엽니다.
  2. 하단의 공유 버튼을 누릅니다.
  3. 홈 화면에 추가 → 추가를 선택합니다.
  4. 홈 화면에 생긴 Velog Alert를 실행합니다.
  5. PC에 표시된 6자리 연결 코드를 입력하고 알림 권한을 허용합니다.

연결 코드는 생성 후 10분 동안 한 번만 사용할 수 있습니다. 만료되면 PC에서 새 코드를 만들어 주세요.

3

연결된 기기

연결된 기기를 확인하는 중입니다.

4

PC가 꺼져 있어도 모든 알림 받기

댓글, 답글, 좋아요, 새 팔로워까지 Cloud에서 약 1분마다 확인합니다. 이 기능을 켜면 현재 Velog access/refresh token을 암호화하여 Push 서버에 저장합니다. Velog 비밀번호는 전송하지 않습니다.

상태 확인 중 Cloud 인증 상태를 확인하고 있습니다.
