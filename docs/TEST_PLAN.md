# Velog Alert V1 QA Plan

## A. 설치/기본 동작

- [x] `chrome://extensions`에서 오류 없이 로드
- [x] Popup이 정상 표시
- [x] 상태가 `정상 작동`으로 표시
- [x] `지금 확인` 클릭 후 최근 확인 시간이 갱신
- [x] `테스트 알림` 클릭 시 OS 알림 표시
- [x] 실제 신규 Velog 활동 알림 표시

## B. 신규 알림 감지

### 댓글

- [x] 다른 계정으로 내 게시글에 댓글 작성
- [x] 다음 검사에서 신규 알림 감지
- [x] Chrome 알림 발생
- [x] 자동 주기 검사로 알림 발생

추가 권장 검증:

- [ ] 동일 댓글 재검사 시 중복 알림 없음
- [ ] Popup `최근 감지` 클릭 시 해당 게시글 이동

### 답글

- [ ] 답글 작성 시 Chrome 알림 발생
- [ ] `post_title`이 없어도 Popup이 깨지지 않음
- [ ] 게시글 URL 이동 정상

### 좋아요 / 팔로우

- [ ] 기본 OFF 상태에서는 OS 알림이 뜨지 않음
- [ ] 신규 감지 히스토리에는 기록됨
- [ ] ON으로 변경한 뒤 새 활동부터 OS 알림 발생

## C. 설정

- [ ] 전체 스위치 OFF → 자동 검사 중단
- [ ] `지금 확인`은 전체 OFF 상태에서도 수동 검사 가능
- [ ] 1/5/10/30분 설정 변경 시 저장
- [ ] Chrome 재시작 후 설정 유지

## D. 초기화/중복

- [x] 신규 설치 직후 과거 알림 대량 발송 없음
- [x] 자동 검사와 수동 검사가 겹쳐도 검사 lock 적용
- [ ] Chrome 재시작 후 기존 알림 재전송 없음

## E. 인증/오류

- [x] Chrome Cookies API 기반 Velog 로그인 확인
- [x] Bearer GraphQL 조회
- [x] Service Worker 직접 cookie fetch의 빈 200 응답 진단
- [x] page bridge fallback 오류 진단
- [ ] Velog 로그아웃 → 로그인 필요 표시
- [ ] 재로그인 후 자동 복구
- [ ] 네트워크 일시 실패 후 다음 검사 복구

## V1 핵심 완료 기준

다음 흐름은 실제 Chrome 환경에서 성공을 확인했다.

```text
새 Velog 활동
  ↓
chrome.alarms
  ↓
Bearer 인증 GraphQL 조회
  ↓
신규 ID 감지
  ↓
Chrome 알림
```

추가 QA 항목은 배포 안정성을 높이기 위한 회귀 테스트로 유지한다.
