# 설치 및 초기 설정

## 0. 현재 배포 방식

Velog Alert는 현재 Chrome Web Store 등록 전입니다.

따라서 다른 사용자가 설치하려면 **배포 ZIP을 내려받아 Chrome 개발자 모드에서 직접 추가**해야 합니다.

> ZIP 파일 자체를 Chrome에 바로 넣는 것이 아니라, 반드시 먼저 압축을 풀어야 합니다.

## 1. Chrome Extension 설치

1. 최신 `Velog_Alert_v2.0.0_..._EXTENSION.zip` 파일을 다운로드합니다.
2. ZIP 파일의 압축을 풉니다.
3. PC Chrome 주소창에 `chrome://extensions`를 입력합니다.
4. 우측 상단 **개발자 모드**를 켭니다.
5. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
6. 압축을 푼 폴더 중 `manifest.json` 파일이 바로 들어 있는 폴더를 선택합니다.
7. Chrome 툴바의 확장 프로그램 메뉴에서 **Velog Alert**를 고정하면 사용하기 편합니다.

정상 설치되면 Velog Alert Popup이 열립니다.

## 2. Velog 로그인 확인

Velog에 로그인한 상태여야 합니다.

Popup에서:

```text
Velog 인증
로그인 확인
```

이 표시되는지 확인합니다.

`세션 갱신 필요` 또는 `로그인 필요`가 표시되면:

1. `https://velog.io`를 엽니다.
2. 로그인 상태를 확인합니다.
3. Velog 페이지를 새로고침합니다.
4. Velog Alert Popup을 다시 엽니다.

## 3. 최초 확인

Popup의 **지금 확인**을 한 번 누릅니다.

최초 확인에서는 이미 존재하던 알림과 팔로잉 Feed를 baseline으로 저장합니다. 따라서 설치 직후 과거 알림이 한꺼번에 뜨지 않는 것이 정상입니다.

## 4. 확인 주기 설정

Popup의 **확인 주기**에서 원하는 값을 선택합니다.

```text
30초
1분 (기본)
5분
10분
30분
```

30초 모드는 Chrome 120 이상에서 사용할 수 있습니다.

## 5. PC 알림 테스트

1. Popup에서 **테스트 알림**을 누릅니다.
2. Chrome/Windows 알림이 표시되는지 확인합니다.
3. 실제 Velog 알림은 다른 계정에서 댓글을 작성하거나, 기존에 팔로우 중인 사용자가 새 게시물을 작성하는 방식으로 확인할 수 있습니다.

## 6. 휴대폰 알림 연결

PC Velog Alert에서 **휴대폰 알림 연결 ↗**을 누릅니다.

### 6-1. PC에서 연결 코드 생성

1. **휴대폰 알림 사용**을 켭니다.
2. **6자리 연결 코드 만들기**를 누릅니다.
3. 화면에 표시되는 코드를 확인합니다.

연결 코드는 **10분 동안 한 번만** 사용할 수 있습니다.

### 6-2. Android

1. Android 휴대폰의 Chrome에서 `https://velog-alert-mobile.netlify.app`을 엽니다.
2. Chrome 메뉴(⋮)에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.
3. 홈 화면에 생성된 **Velog Alert**를 실행합니다.
4. PC에 표시된 6자리 코드를 입력합니다.
5. **알림 허용 및 연결**을 누릅니다.
6. Android의 알림 권한 요청을 허용합니다.

### 6-3. iPhone

1. iPhone의 Safari에서 `https://velog-alert-mobile.netlify.app`을 엽니다.
2. Safari 하단의 **공유** 버튼을 누릅니다.
3. **홈 화면에 추가**를 선택하고 **추가**를 누릅니다.
4. Safari 탭이 아니라 홈 화면에 생성된 **Velog Alert**를 실행합니다.
5. PC에 표시된 6자리 코드를 입력합니다.
6. **알림 허용 및 연결**을 누르고 iOS 알림 권한을 허용합니다.

> iPhone에서는 Web Push를 사용하기 위해 홈 화면에 추가한 Velog Alert 앱에서 연결을 진행해야 합니다.

## 7. 휴대폰 연결 확인

PC의 휴대폰 알림 설정 화면으로 돌아와 **새로고침**을 누릅니다.

연결에 성공했다면 기기 이름과 **알림 연결됨** 상태가 표시됩니다.

그 다음 **휴대폰 테스트 알림 보내기**를 눌러 실제 휴대폰에서 Push가 도착하는지 확인합니다.

## 8. 권장 기본값

```text
전체 알림       ON
댓글            ON
답글            ON
팔로우 새 글    ON
좋아요          OFF
새 팔로워       OFF
확인 주기       1분
```

더 빠른 알림을 원하면 확인 주기를 30초로 변경할 수 있습니다.

## 9. 팔로잉 새 글 테스트

1. `팔로우 새 글` ON 확인
2. `지금 확인`으로 현재 Feed baseline 생성
3. **이미 이전부터 팔로우하던 사용자**가 새 게시물을 작성
4. 설정한 확인 주기만큼 대기
5. PC와 연결된 휴대폰에서 새 게시물 알림 확인
6. 알림 클릭 후 해당 Velog 게시글 이동 확인

새 사용자를 방금 팔로우한 경우 Velog가 과거 게시글을 Feed에 추가할 수 있으므로, Velog Alert는 해당 글들을 신규 알림에서 제외합니다.
