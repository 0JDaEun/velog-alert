# 설치 및 초기 설정

## 1. 개발자 모드 설치

1. `Velog_Alert_v1.1.0_SOURCE.zip` 압축 해제
2. Chrome에서 `chrome://extensions` 접속
3. **개발자 모드** 활성화
4. **압축해제된 확장 프로그램을 로드합니다** 선택
5. `manifest.json`이 있는 `velog-alert` 폴더 선택

## 2. Velog 로그인

Velog에 로그인한 상태여야 합니다.

Popup에서:

```text
Velog 인증
로그인 확인
```

이 표시되는지 확인합니다.

`세션 갱신 필요` 또는 `로그인 필요`가 표시되면:

1. Velog 페이지를 엽니다.
2. 로그인 상태를 확인합니다.
3. 페이지를 새로고침합니다.
4. Popup을 다시 엽니다.

## 3. 최초 확인

`지금 확인`을 한 번 누릅니다.

최초 확인에서는 기존 알림을 baseline으로 저장하기 때문에 OS 알림이 발생하지 않습니다.

## 4. 실제 동작 테스트

1. 다른 Velog 계정에서 내 글에 새 댓글 작성
2. `지금 확인`을 누르지 않음
3. 확인 주기가 1분이면 약 1~2분 대기
4. Chrome/Windows Notification 확인
5. Popup에서 `마지막 자동` 시각 갱신 확인
6. Notification 클릭 후 게시글 이동 확인

## 5. 권장 기본값

```text
전체 알림     ON
댓글          ON
답글          ON
좋아요        OFF
팔로우        OFF
확인 주기     1분
```

## 6. 팔로잉 새 글 테스트

v1.1.0에서는 Popup의 `팔로우 새 글`이 기본 ON입니다.

업그레이드 직후 첫 확인은 현재 Feed를 baseline으로 저장하므로 기존 글 알림은 발생하지 않습니다.

테스트하려면:

1. `팔로우 새 글` ON 확인
2. `지금 확인`으로 baseline 생성
3. 이미 팔로우 중인 다른 사용자가 새 게시물을 작성
4. `지금 확인`을 누르지 않고 확인 주기만큼 대기
5. `Velog 새 게시물` Chrome Notification 확인
6. Notification 클릭 시 해당 게시글로 이동 확인
