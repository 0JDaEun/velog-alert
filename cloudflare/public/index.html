VELOG ALERT

휴대폰 알림 연결

앱스토어 설치 없이 홈 화면에 추가하고 알림을 받을 수 있습니다.

STEP 1

홈 화면에 추가

이 웹앱을 홈 화면에 추가하세요.

iPhone Safari의 공유 버튼 → 홈 화면에 추가 → Velog Alert 실행
홈 화면 앱으로 실행 중
STEP 2

PC 연결 코드 입력

PC의 Velog Alert에서 표시된 6자리 코드를 입력하세요.

연결 전

홈 화면에 추가한 뒤 연결 코드를 입력하세요.

Velog 비밀번호는 사용하지 않습니다. Always-on을 직접 활성화한 경우에만 Velog 인증 토큰을 자신의 Cloudflare Worker에 전송하며, 서버에는 AES-GCM 암호문으로 저장합니다.
